# openac-gamedata

The game database (`gameinfodb.ugd`) for the MossTank plugin, generated from
ACE's open world data.

Download: https://github.com/eriknihlen/openac-gamedata/releases/latest/download/gameinfodb.ugd

Build it yourself: `dotnet run --project src/OpenAC.GameData -c Release -- build`
